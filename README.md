# Dot Motion Illusion

ドットの動きの錯視を、ブラウザで試せるデモです。

2色のドットを斜めの列に並べ、全体を一定の速さで上下に動かします。ドットは縦にまっすぐ動いているだけですが、色・間隔・速度の組み合わせによって、列が横や斜めに流れているように見えます。速度・ドットのサイズ・間隔・色を変えながら、見え方の違いを確かめられます。

## 操作

| 操作 | 内容 |
| --- | --- |
| 「一時停止」/「再生」ボタン | アニメーションを止める・再開する |
| スペースキー | 同上(入力欄などにフォーカスがないとき) |
| 「初期値に戻す」ボタン | すべての設定を初期値に戻す |

OS で「視差効果を減らす」「アニメーションを減らす」などの設定が有効な場合は、停止した状態で始まります。「再生」を押すと動き出します。

## 設定項目

| 項目 | 範囲 | 初期値 | 内容 |
| --- | --- | --- | --- |
| 速度 | 10〜2000 | 80 | ドットが動く速さ(px/秒) |
| サイズ | 2〜15 | 7.5 | ドットの半径(px) |
| 横の間隔 | 2〜30 | 6 | 隣り合う縦列どうしの横の間隔(px) |
| 縦の間隔 | 2〜40 | 22.5 | 隣り合う縦列どうしの縦のずれ(px)。斜め列の傾きが決まる |
| 列どうしの間隔 | 8〜100 | 31.5 | 斜め列どうしの垂直距離(px) |
| 色A | — | `#78a8c5` | 偶数番目の縦列のドットの色 |
| 色B | — | `#ffffff` | 奇数番目の縦列のドットの色 |
| 背景 | — | `#000000` | 背景色 |

## 仕組み

描画は Canvas 2D で行っています。

- ドットは「縦列」ごとに色A・色Bを交互に塗り分けます。
- 隣の縦列は「縦の間隔」ぶん上にずらして置くので、ドットは斜めの列になります。
- 斜め列どうしの垂直距離が常に「列どうしの間隔」になるよう、縦方向の繰り返し間隔は `列どうしの間隔 × √(横² + 縦²) ÷ 横` で計算しています。
- 毎フレーム、全体を `速度 × 経過時間` だけ縦に動かします。画面に入る範囲のドットだけを描きます。
- 高解像度ディスプレイでもぼやけないよう、Canvas の解像度は `devicePixelRatio` に合わせています。
